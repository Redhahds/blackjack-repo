# blackjack-repo
Jeu de blackjack avec des règles simples

Carte.java : 
Décrit le comportement d'une carte ainsi que ses particularités
(exemple : quelle est la couleur de la carte ou bien sa valeur)

Main.java :
Décrit le fonctionnement d'une main cad les cartes à disposition du joueur ou du croupier ainsi que la possibilité de connaitre le score (et donc si le joueur/croupier a gagné ou perdu ou autre)

Paquet.java :
Décrit le fonctionnement d'un paquet de cartes classique (54 cartes ainsi que la possibilité de piocher ou de mélanger)

App.java : 
Fichier permettant d'exécuter le programme dans la console

Partie.java :
Décrit le fonctionnement d'une partie complète de BlackJack (à qui le tour, qui pioche, qui reste, etc...)
